#+DESCRIPTION: MELPA 装多了，容易忘了 Emacs 本身就是座宝库。本文整理六月 Emacs Carnival 总结的四条翻家底路径：C-h r 翻概念索引、list-packages 只看内置包、C-h m 问当前模式要说明书、C-h n 翻 NEWS 旧报纸，每条配可直接运行的验证代码。

MELPA 上的包太多了，装着装着就容易忘掉一件事，Emacs 本体就是座宝库，将近两百万行 Lisp 和 C 代码，里面藏了多少好东西，谁也说不全。2026 年 6 月 Emacs Carnival 的主持人 [[https://rossabaker.com/blog/underappreciated-emacs-built-ins/][Ross A. Baker]] 把这期主题定成「被低估的 Emacs 内置功能」，给出了四条翻家底的路径。我照着走了一遍，把路径和验证代码一起记在这里。

* 翻手册的概念索引（C-h r）

最正统的入口反而最容易被忽视，那就是官方手册。=C-h r= 打开 Emacs manual 后别从头读，直接翻到末尾的 Concept Index（概念索引）。它是把整本手册讲过的概念按字母顺序排成的一张关键词表，每个词后面注明讲它的章节在哪。它可以解决「知道想干什么，但不知道 Emacs 里管这叫什么」的问题，比如想找「有没有办法提醒我开会」，按字母翻到 reminder，顺着链接就能摸到 calendar 和 diary 一大家子。手册是官方维护的一手资料，比博客文章可靠得多。

* 在包列表里只看内置包（M-x list-packages）

内置功能在包管理系统眼里也是包。 =M-x list-packages= 打开列表后按 =/ s= ，状态选 built-in，剩下的全是原装货。嫌开列表麻烦，直接问包系统也一样。

#+begin_src elisp :results value
(require 'package)
(list (package-built-in-p 'wdired)
      (package-built-in-p 'calc)
      (package-built-in-p 'magit))
#+end_src

#+begin_example
((wdired . [nil nil "Rename files editing their names in dired buffers"]) (calc . [nil nil "the GNU Emacs calculator"]) nil)
#+end_example

wdired 和 calc 返回的是版本信息（内置），magit 是 nil（第三方）。这个判断跟你装没装过 MELPA 毫无关系。

* 问当前模式要说明书（C-h m）

一个 mode 用久了，常用的就那几个键，其余全成了盲区。 =C-h m= 会把当前 buffer 里激活的所有模式连同各自的按键列成一页清单。隔段时间在 mode 里跑一次，总能撞见几个没见过的绑定，算是最省力的考古方式。

* 翻旧NEWS（C-h n）

=C-h n= 打开的是当前版本的 NEWS。真正的好戏在硬盘上，data-directory 目录下躺着历代 NEWS 文件，最老的 NEWS.1-17 把头十七个版本打包在一起，往后一年一份排到 NEWS.29（当前版本 30 的那份单独放着）。

#+begin_src elisp :results value
(directory-files data-directory nil "NEWS")
#+end_src

#+begin_example
("CALC-NEWS" "EGLOT-NEWS" "ERC-NEWS" "MH-E-NEWS" "NEWS" "NEWS.1-17" "NEWS.18" "NEWS.19" "NEWS.20" "NEWS.21" "NEWS.22" "NEWS.23" "NEWS.24" "NEWS.25" "NEWS.26" "NEWS.27" "NEWS.28" "NEWS.29" "NEWS.unknown" "NXML-NEWS" "ORG-NEWS")
#+end_example

想知道某个功能是哪个版本进来的，翻对应年代的NEWS最直接。

下次手痒想装包，先按这四条路径翻一翻，要找的东西说不定早就在机器里了。
